# Personal Budget Tracker

A small Python notebook project for recording income and expenses, computing account summaries, and visualizing personal financial activity.

## Features

- Record income and expense transactions
- View transaction history
- Calculate total income
- Calculate total expenses
- Calculate remaining balance
- Visualize spending using charts

## Repository Structure

```text
.
├── Budget_tracker.ipynb
├── transactions.csv
└── README.md
```

## Usage

Open `Budget_tracker.ipynb` in Jupyter Notebook or JupyterLab and run the cells.

The example transaction data is stored in `transactions.csv`.

## Tech Stack

**Python · Pandas · Matplotlib · Jupyter Notebook**

## Project Status

This is an early learning project focused on basic data manipulation, aggregation, and visualization. It is kept as a record of Python/data-analysis practice rather than a production application.
